## Build

- [x] `snapshot.ts`. It never opens anything under the real folder with `sqlite3` or any tool that can write. It copies `matches.db`, `matches.db-wal` and `matches.db-shm` with plain reads, retrying until no source file changed during the copy, and runs `integrity_check`, `VACUUM INTO` and the journal-mode change on the copy. - [x] `settle.ts`, `states.ts`, `capture.ts`, `diff.ts`. `capture.ts` writes `<state>.meta.json`, `timing.json` and `seam.log`, and fails a state on a settle timeout, a missing expected element, a card placeholder or a clipped card, and the run on a seam fault, a blocked write or a write outside the run folder.
