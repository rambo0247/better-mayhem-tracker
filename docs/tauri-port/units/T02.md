## Waivers and deviations

- W1. `--disable-gpu`. The plan says lanes keep the GPU on, from a prototype that saw 74 differing pixels with it off. On this fixture the GPU-on harness did not repeat: three full GPU-on runs differed on 5 of 26 states per pair, up to 121 pixels, and summed over all pairs of six runs the differing pixels at pixelmatch 8 threshold 0.03 were 1,359, 175 at 0.04, 116 at 0.05, 81 at 0.06, 16 at 0.07, and 0 at 0.08 (`determinism.log`). Reloading `friends-default` 12 times in one launch gave 3 to 6 distinct renders with the GPU on (`--num-raster-threads=1`, `--disable-features=...`, a window resize before the shot, and synchronous image decoding did not help) and 1 distinct render with `--disable-gpu`. With the GPU off and before the scrollbar fix, run 1 against run 3 matched on 22 of 26 states (4 Match History states differed by 5 to 6 pixels at the right edge, the overlay scrollbar), logs `ng1.log` to `ng3.log` and `ng-determinism.log`. After the fix, see lane 1. The deviation is `--disable-gpu` in `run-electron.ts`. `PARITY_ELECTRON_ARGS` appends flags for experiments. A card export in the real app runs with the GPU on, so T25 compares against a GPU-off baseline of the same markup, and the cross-engine budget absorbs the antialiasing difference (inferred, not measured here).
- W2. The same-engine policy is pixelmatch `threshold` 0.03, `includeAA` on, zero pixels. `pixelmatch` 8.0.0 uses an OKLab distance, and its 0.03 is stricter than the 0.03 of the 5.3.0 the prototype used: the same GPU-on pairs gave 32 differing pixels at 5.3.0 and 172 at 8.0.0 at threshold 0.03. The tool keeps the plan's 0.03 and reports the one residual (`game-card-default`, 18 pixels, in 2 of 3 run pairs). The decision for the root and operator is whether the same-engine gate moves to 0.04, which passes every GPU-off pair recorded here, or the one state gets a documented mask. The owner did not loosen the gate.
- W3. `sqlite3 -readonly` fails on the live WAL database (`unable to open database file`), so `snapshot.ts` falls back to copying the three files and running `.backup` on the copy. The fallback prints a line when used.
- W4. `bun lint` needs `--flavor eslint`, per the root's directive and T01's finding, and the proof is `bun lint --flavor eslint --list-files` listing 20 files.
- W5. `/deslop` and `/no-comments` are not installed. The Comments rule was applied by hand: the only comments left are `eslint`-style reasons for a non-obvious why.
- W6. Screenshots hide the overlay scrollbar with `::-webkit-scrollbar{display:none}` in the kill switch, because it appears or fades between loads. T07 injects the same CSS in the Tauri page.
- W7. Settle counts only images within a screen of the viewport. Lazy images far below the fold never load, and waiting on them hung the Friends page for minutes.
- W8. The plan says 15 routes. The router has 14 routes in the layout and 2 card routes, and the table has a default state for each (16).
- W9. Playwright 1.66.0-alpha-2026-11-22 launched Electron through `_electron.launch`. The 1.65.1 fallback was not needed.
- W10. Not run by the owner, since they need the operator's data folder or Windows: lane 2 and lane 9. `cargo clippy` in `tauri/` was not run because this branch changes nothing under `tauri/`. `bun run lint`, `bun run fmt:check`, `bun run typecheck`, `bun test`, and `cargo fmt --check` pass there at this head.
- W11. Capture size is 1280 by 820 content, the size the app opens at (`src/main/index.ts`), with the rail state at 1179 by 820, the narrow state at 900 by 820, and the two card routes at 1200 wide with the window resized to the card's published height.
