## Isolation

- The fake listens on 127.0.0.1 only. Its CA and leaf are made at run time, named "not Riot", and never written outside the run's fake folder.
- Electron finds the fake only through the seam: the default League install folder maps to `<fake dir>/league`, every other League and Riot path stays hidden, and the process scrape stays blocked.
- The seam adds the fake CA to every explicit `ca` list in `tls.createSecureContext`. Riot's root stays in the app. This is needed because the app passes `ca: RIOT_ROOT_CA`, which replaces Node's own roots, so `NODE_EXTRA_CA_CERTS` would not reach it (as `_design/T19-how.md` warned).
- With `SEAM_FAKE_DIR` set, `net.Socket.prototype.connect` refuses any loopback port that is not one of the fake's, and logs each connection in `seam.log`. Port 2999 is rewritten in every run, to the fake's port or to port 1, which refuses.
- No code here reads the real client's lockfile or connects to it. T03 lane 10 is the root's.

## Waivers and notes

- Backfill needs Riot's match-history hosts, which the seam blocks. The seam redirects `*.pp.sgp.pvp.net` to a plain-HTTP fake on 127.0.0.1 when a fake runs.
- `connecting` is held by making the seam swallow the connect loop's 5000 ms `setInterval`. This depends on that interval staying 5000 ms in `lcu.ts`.
