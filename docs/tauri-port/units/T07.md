## Build

- [x] `parity_driver.rs`, compiled only with `--features parity-driver`. A release build with the feature fails: `cargo check --release --features parity-driver` stops on `compile_error!("the parity-driver feature is for debug builds only")`, exit 101 (`parity/out/evidence/release-feature-refused.log`). It listens on `127.0.0.1:0` and prints `bmt-parity-driver-v1 listening 127.0.0.1:<port>`. It refuses to start without a `BMT_PARITY_TOKEN` of at least 16 characters, and refuses any request from a non-loopback peer (403) or without `Authorization: Bearer <token>` (401, constant-time compare). Deviation from the plan's verb list, per the root's design: the driver offers primitives (`eval`, `mouse`, `key`, `wheel`, `resize`, `viewport`, `navigate`, `reload`, `snapshot`, `info`, `quit`). The plan's verbs `click`, `hover`, `type`, `key`, `scroll`, `resize`, `navigate`, `dom`, `geometry` are served by `run-tauri.ts` through `drive.ts --run`, the same control protocol `run-electron.ts` serves, so one definition of each verb drives both apps.
  - macOS: `eval` is `callAsyncJavaScript` in the page world, so promises are awaited and exceptions come back with WebKit's message. Mouse and key events are `NSEvent`s handed to the `WKWebView` itself, never through the window, so AppKit never makes the window key or activates the app. Points are offset by WebKit's public `obscuredContentInsets` (see Findings). `wheel` scrolls from script: a wheel `NSEvent` can only be built from a `CGEvent` at a screen position, which WebKit then reads in the wrong space for a window not under the real pointer.
  - Windows: everything is DevTools Protocol through `ICoreWebView2::CallDevToolsProtocolMethod`, the channel Playwright uses for Electron: `Runtime.evaluate` with `awaitPromise`, `Input.dispatchMouseEvent`, `Input.dispatchKeyEvent`, `Emulation.setDeviceMetricsOverride`, `Page.captureScreenshot`.
  - Every call that waits for the main thread waits on a channel with a timeout, so a failed downcast cannot hang a request.
  - Under the feature the app is an accessory app on macOS (no Dock icon), `activate_ignoring_other_apps(false)`, `focused(false)`, at 40,40, with an `NSProcessInfo` activity held against App Nap, and a private (`incognito`) store. It never calls focus or activate.
  - Data and clock injection for later units: the driver takes any initialization script from `BMT_PARITY_INIT`, any renderer from `BMT_PARITY_RENDERER_DIR`, any asset cache from `BMT_PARITY_ASSETS`. The T09 data folder and a Solid build's clock go through the same variables with no driver change.
- [x] `snapshot/mac.rs`: `takeSnapshotWithConfiguration` with `afterScreenUpdates`, the viewport rect, and `snapshotWidth = width × scale ÷ backing`, then TIFF, `NSBitmapImageRep`, conversion to sRGB, PNG. On the operator's display WebKit hands back `sRGB IEC61966-2.1` already, so the conversion is a no-op here (`facts` in each meta file). `snapshot/win.rs`: `Page.captureScreenshot` through the same CDP helper the driver uses. Both are outside the feature for T25.
- [x] `run-tauri.ts` launches the driver build with a fresh token, `TZ=America/New_York`, `LANG=en_US.UTF-8`, `-AppleLanguages (en-US) -AppleLocale en_US` on macOS, Chromium switches matching `run-electron.ts` on Windows (sRGB, `--disable-gpu`, `--lang=en-US`, no occlusion throttling), the same frozen page clock (`seam.cjs`'s `Date` proxy in the init script), the state's viewport, and writes `control.json` in T02's shape plus `driverPort`. It fails when the page's zone is not `America/New_York`.
- [x] `replay-api.js` answers `window.api` from T05's goldens, built against `origin/port/T05-goldens:parity/goldens/FORMAT.md` (version 1, read at `b617b82`). Matching follows FORMAT.md: canonical args, lowest `seq`, read group first, then `default`, else `ReplayMiss: method(args)`. Write groups advance a cursor per channel and args. Settings written are read back, across the reload every state does (kept in `sessionStorage`, which `applyState` clears before `pre`). Error outcomes reject with Electron's `invokeMessage`. The 11 `on*` subscriptions return unsubscribe functions and can replay a scenario's `events/*.jsonl`. The method list comes from `src/shared/api.ts` `INVOKE_CHANNELS` and the event list from `src/preload/index.ts`, parsed, so there is no second list. Canonicalization is a local copy of `canon.ts`'s rule (sorted keys, no clock masking, since call arguments carry no clock), because `canon.ts` is on T05's branch, not this one.
