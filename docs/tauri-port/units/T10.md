## Waivers

- macOS tray double-click: Tauri reports none on macOS. Electron registers one, but the left click opens the menu there anyway.
- Dock Quit and logout on macOS go through `terminate:`, which tao does not route to `ExitRequested`, so they skip the final fetch. Electron runs `before-quit` for them.

## Blockers and decisions for the root

- Electron's traffic lights cannot be pictured: no Screen Recording, and a native FFI capture inside Electron (koffi) was refused by the permission system. The Tauri side is drawn in-process by AppKit (`cacheDisplayInRect`) over the webview snapshot. Grant Screen Recording or approve an in-Electron capture for a true pixel diff.
- Golden replay: `window:is-maximized` `maximized` fails under the mock runtime, whose `is_maximized` is always false. CI has no goldens so it does not fail there. `tests/golden.rs` (T08) needs to skip or stub window state.
- Window dragging on macOS: Electron's renderer uses `-webkit-app-region: drag`, which WKWebView ignores. The capability now allows `start_dragging` and `internal_toggle_maximize`, so the Solid UI (T27/T38) needs `data-tauri-drag-region` on the title bar. WebView2 honors `app-region` on Windows.
- Windows lanes 2 and 8 need a fixture on the runner, which decision E2 keeps off GitHub.
