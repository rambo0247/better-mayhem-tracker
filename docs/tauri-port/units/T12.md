## Float exactness

Every value is an `f64`. The sum runs in the TypeScript's order: six unscaled components, then the multikill, carry, and win bonuses, then one multiply by `SCALE`. `Math.max`, `Math.min`, and `Math.round` are ported with their JavaScript edge cases (`NaN` wins, signed zeros, half rounds toward positive infinity). Map semantics (SameValueZero keys, a repeated participant id keeping its slot) follow the TypeScript.

`ratio ** 1.3` is the one call where engines can differ. Evidence, measured on this Mac.

- V8 main implements `Math.pow` with LLVM libc's pow since V8 15.0, and Electron 44.4.5 ships V8 15.2.124.28. A correctly rounded pow and macOS libm's pow disagree on 282 of 200,000 random inputs in (0, 1), checked against Python `decimal` at 60 digits.
- A fixture copy crafted so 658 owners' damage ratios fall on inputs where the two disagree predicts different `score_raw` bits on 98 games. Trunk Electron's backfill of that copy (through `run-electron.ts`) matched the macOS libm prediction on 669/669 games and the correctly rounded one on 571/669. Electron on macOS therefore uses the platform `pow`, which is what Rust's `powf` calls.
- So `op_score.rs` uses `f64::powf`. On Windows that is the UCRT `pow`, which is presumably what Electron's V8 calls there too. That is unproven until lane 7 runs on `windows-latest`.

## Handoffs and decisions for the root

- Champion class data is an argument (`ChampionClasses { version, classes }`), not managed state, because Data Dragon loading is T22. Electron's startup order, `waitForChampionData().then(checkScoreBackfill)` with `lcu:games-updated` on true, belongs to whoever loads champion data. T20 needs the current classes for `insert_game_full` before T22 exists; it can pass `ChampionClasses::none()`'s empty map, which is what Electron scores with before any data loads, and the later backfill corrects it as Electron's does. Lane 6 can only run once that wiring exists.
- `insert_game_full` rejects a payload whose `gameId` is not an integer with a thrown `TypeError` before writing. Electron throws too (a SQLite datatype or NOT NULL error) and rolls back, so only the message differs.
- `/deslop` and `/no-comments` are not installed; their rules were applied by hand.
