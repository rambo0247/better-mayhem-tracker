- [x] Parity builds use `ParityWeb`: every request fails as a blocked fetch, unless `BMT_PARITY_WEB` names a loopback base, then `https://<host>/<path>` goes to `<base>/<host>/<path>`.
- [x] Traversal. The parser decodes each segment strictly (malformed escape or non-UTF-8 is a 400, as `decodeURIComponent` throws), refuses any segment that is all dots or holds `/`, `\`, `:` or NUL after decoding, allows only `latest`, `pbe` and `NN.NN` branches, and applies Electron's image path regex. Copies are always read at `root/<patch>/<hash>`, so no request can name a file outside the cache. Electron's URL parser would resolve `..` instead of refusing it. Refusing is stricter and was the root's order.
- [x] Windows. WebView2 routes custom schemes only as `http://<scheme>.localhost` (wry's filter), and wry 0.57.3 undoes that rewrite before the handler runs (`src/webview2/mod.rs:1217`, `src/custom_protocol_workaround.rs:30-35`), so the handler sees `asset://localhost/<kind>/...`. On Windows the parser reads host `localhost` as that form, with the first path segment as the kind (fix round 1, H1). On macOS `asset://localhost/...` is kind `localhost`, which Electron answers 400, and host `asset.localhost` is refused on both, since no engine hands the handler that form (fix round 2). `asset-url.ts` rewrites `asset://` to `http://asset.localhost/` under WebView2 for the Solid UI. URLs a command returns (a resolved augment icon) go through `assets::for_webview` at the command boundary, so stored files keep `asset://` and stay Electron's. Unproven on `windows-latest` until lane 2 runs.

### Recorded, not changed

- Backoff clock. Electron's outage and retry windows read `Date.now()`, wall time. The port reads tokio's `Instant`, which is monotonic: a wall clock moved back during an outage stretches Electron's window and not ours, and one moved forward ends Electron's early. Kept, since a monotonic window is the intent.
- Augment, item and spell maps stay integer-keyed: an id that isn't a non-negative integer below 2^32 - 1 is dropped or ordered among the integers, where JavaScript would keep it as a string key after them. CommunityDragon's ids are all such integers.
