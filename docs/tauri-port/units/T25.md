## Exactness: E9's private call against the public path

Both measured at `d99d1e0` against Electron 1.2.1 exporting the same cards from the same fixture, cross-engine pixel gate (pixelmatch threshold 0.1, AA off). E9's default is applied: the private call is used, the public path is the fallback.

| Card | Path | Size | Differing pixels | Worst 64 CSS px tile |
| --- | --- | --- | --- | --- |
| Game 5684865505 | `_setOverrideDeviceScaleFactor:` 1.5 | 1800 x 1427, same as Electron | 1.116% | 6.63% |
| Season set-3, queue 2400, one account, friends hidden | `_setOverrideDeviceScaleFactor:` 1.5 | 1800 x 2604, same as Electron | 0.782% | 12.74% |
| Game | public path, backing scale 2 | 1800 x 1434, Electron 1427 | 7.13% over the shared 1427 rows | 42.43% |
| Season | public path, backing scale 2 | 1800 x 2613, Electron 2604 | 4.65% over the shared 2604 rows | 35.34% |

- The plan's prototype measured 1.56% (private) and 7.35% (public). The private path now measures 1.12% on the game card, because T27's portrait fix is in.
- At the public path the page lays out at device ratio 2, so it measures 956 CSS px tall where Electron's measures 951, and rows shift. That fails on size before pixels, which is why E9's default matters.
- What differs on the private path, from the side-by-side images: glyph edges of the display type and small text (CoreText against Skia), and on the season card the 112 px profile icon's downscaled edges and the gold glow next to it. Layout is the same: every row lands at the same height and both cards have Electron's height to the pixel.
- Neither card passes the Appendix A page budget of 0.3%, and the season card's worst tile is over 8%. This is the gotcha the design note predicted. It needs the root's or the operator's call under E1: a card-specific budget or a waiver. The layout gate was not run, because the card window is destroyed before geometry could be dumped; matching heights are the layout evidence.
- Both apps are deterministic. Two runs of each, an hour apart, gave pixel-identical cards.

## Waivers and decisions for the root

- The cross-engine page budget fails for both cards (above). Needs an E1 call.
- Lanes 4, 5, 7 and 10 are not run, for the reasons given.
- Electron's `writeFile` error reads "ENOENT: ..." from Node; Tauri's reads Rust's I/O error text. Only a failing write shows it.
- The dialog is parented only to a visible window; Electron always passes the sending window.
- `parity_driver::configure` is applied to card windows in parity builds, so card page loads also bump the driver's load counter. A driver `navigate` or `reload` racing an export could return early.
