## Build

- [x] Solid 2 rules everywhere. Props are read through `props.x` (or `omit` in the icon wrapper). Text, number and range inputs report through `onInput`. Early returns are `<Show>`. `useEffect(fn, [])` became `onSettled` returning its cleanup. `class` with array and object forms, kebab-case `style` keys, and every size a `px` string. `react-isms.ts` counts zero of every pattern.
- [x] Hooks keep their React names, so page owners find them, but take and return accessors: `useIpc(fetcher, deps)` splits the tracked deps from the fetch, the way `createEffect` splits compute from apply; `useViewState` is a signal that stores every value; `useAugmentData(() => patch)` and `useItemData` share one per-patch cache helper; `useMatches(() => filters)` compares filters by value.
- [x] Routes. `@solidjs/router` 2.0.1 has no `HashRouter` or `<A>`: `createRouter({ routes, history: hashHistory() })` with the same `#/` paths, the Layout as the parent route of the fourteen in-layout routes, and the two card routes outside it. Nav links are plain anchors to `#/path`; their active state comes from `useLinkState`, and they set `aria-current="page"` when active, as React's `NavLink` did. `location.state` is the router's `navigate(to, { state })` and `useLocation().state`. Each page unit adds `tauri/src/pages/<Page>.tsx` and `App.tsx` picks it up by name through an eager `import.meta.glob` that leaves `*.test.tsx` out. The Vite build fails on any test module or any `bun:` or `node:` import left in a chunk.
- [x] The content div is keyed by pathname (`<Show when={location.pathname} keyed>`), so the page eases in on each navigation as React's `key={pathname}` made it do.
- [x] First render waits for `getSetting("remember_filters")` and `initViewState`, as `src/renderer/main.tsx` does.
- [x] `-webkit-app-region` is gone. The sidebar's top strip, the brand header and the title bar carry `data-tauri-drag-region="deep"`, which drags from anywhere in the subtree except clickable elements, the way Electron's `drag` did; the window controls carry `data-tauri-drag-region="false"` for Electron's `no-drag`.
- [x] ChampionIcon. A `span` with `overflow: hidden` at the tile's size, carrying the caller's classes and title, and an `img` drawn at `calc(100% / 0.88)` offset by `calc(-6% / 0.88)`, which crops 6% from each side in WebKit and Chromium alike. The span is marked `data-parity-skip`, and `parity/geometry.js` records it as the `IMG` Electron drew, with the span's box (the tile). RecordCard's faint icon carries `[-webkit-mask-image:...]` beside `[mask-image:...]`; the built CSS holds both.
- [x] `first-content`. `lib/perf.ts` `reportFirstContent()` sends `page_event("first-content")` two frames after it is called, once per launch. The route placeholder calls it when it settles; a page calls it when its first row paints (T37 for Match History). `page_event` logs `[bmt pid=N] page first-content N ms after process start` when `BMT_PERF=1`, to stdout and appended to `BMT_PERF_LOG`. T06's `parseTauriLines` matches it.
- [x] HoverCard renders through `Portal` to `document.body`, off-screen and hidden until measured, then placed below or above the trigger as in React. `content` is a render function, so a table of icons builds no card until one is hovered.
- [x] `lib/api-shim.ts` exports `api`: `window.api` when something provides it (the replay API in parity runs, the preload shape T08's `api.ts` will install), else an object whose every channel rejects with `Error invoking remote method '<channel>': Error: not ported`. Switching to T08's `api.ts` is one import in this file.

## Findings

- `@solidjs/router` 2.0.1 has no `HashRouter`, `<A>`, `NavLink` or `<Route>`; routes are config objects for `createRouter` with `hashHistory()`, and links are plain anchors. Every page unit follows this.
- `<Show when={x}>` treats `0` as false. SummonerIcon checks `iconId != null`, as React did, because profile icon 0 exists.
- Each read of a JSX prop builds its nodes again, so a component that tests a slot and then renders it (`{props.kicker && <div>{props.kicker}</div>}`) builds it twice. PageHeader and StatCard resolve slots once with `children()`.
- A DOM node can be in one place only, so RecordCard, which draws its icon twice, takes the icon component.
- happy-dom compares a select's value strictly, which exposed a real ordering bug: QueueSelect wrote a number value before its options existed. Fixed for WebKit as well.
- The plain `bun test` that `tauri-ci.yml` runs loads Solid's server build; the test preload now resolves the DOM build itself.
- `parity/test/guards.test.ts` "aborts a write under a folder mapped as real" timed out once at 5 s locally under load and once on CI (run 45154603213); it passed on two local reruns. It is T02's test and unrelated to this unit.
- The commit message of `0db3c32` says 77 prop combinations; the file has 72 (corrected in `664a9b6`'s message).
