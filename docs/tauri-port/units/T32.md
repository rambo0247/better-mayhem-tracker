# T32: Friends, friend detail, and group detail pages

Branch `port/T32-friends`, based on `port/T27-ui-shell` 590cfaf.

## Files

- `tauri/src/pages/Friends.tsx`, `FriendDetail.tsx`, `GroupDetail.tsx`
- `tauri/src/components/SharedGameRow.tsx`, `BackToFriends.tsx` (owned here, per the plan)
- `tauri/src/pages/*.test.tsx` and `tauri/src/testing/ssr.ts`, the harness the tests share

## Decisions

- `BackToFriends` is a plain `<a href="#/friends" state="{json}">`, which is how @solidjs/router 2 carries link state. Friends reads it from `useLocation().state` once, because the layout remounts the page per path.
- The `FriendDetail` champion grid measures in a `createEffect` whose compute tracks the champion list, with a `ResizeObserver` and cleanup, matching the `useLayoutEffect` it replaces.
- Row clicks in `Friends` stay `onClick` on the `tr` as in Electron, so the DOM is unchanged. `friendPath` and `groupPath` are exported for the tests.
- Unit tests run without a DOM: `testing/ssr.ts` compiles the pages for the server (vite's `transformWithOxc`, then `@solidjs/compiler`), mocks the IPC hooks, router and `api`, and asserts on the rendered string. It adds no dependency and touches no shared file.
