The detail FAIL is a replay-data miss, not a page bug.

- The state's `{championId}` is `getChampionStats()[0]`, which is champion 26 (Zilean). Electron's baseline renders the real fixture data for 26: 58 games, 56.9% win rate.
- The replay has no `getGlobalChampionDetail` golden for 26. `replay-api.js` falls back to the case named `default`, whose args are `[79]` (34 games, 47.1% win rate), and does not list it in `replayMisses` (empty). The page shows the Zilean header over Gragas numbers.
- The 58.73 px shift T07 flagged is the same row. The item and augment tables have different row counts (Electron 51 and 77, Tauri 55 and 74) and the stat cards differ in height.
- Proof: with `championId` forced to 79 in a scratch copy of the runner (Electron captured by `capture.ts --app electron`, same fixture), the page passes: 0.2678% differing, 609 against 609 elements, 0 beyond 1 px, worst 0.33 px.
- Root decision: record a `getGlobalChampionDetail` golden for the first champion of `getChampionStats`, or have `resolveVars` take the id from the golden's args. Either belongs to `parity/`.

No Appendix A engine difference is needed: the three list states pass inside the policy on their own.

## Query behavior (probed, Electron and Tauri)

A scratch copy of the runner with a probe step recorded `location.hash` and `view:global.params` after each step.

- Deep link `#/global?tab=items&patch=16.22`: both open on the Items tab with the patch (lane 7 PASS).
- Open a champion with `?patch=16.22&queue=2400`, then the back link: both land on `#/global?patch=16.22&queue=2400` (lane 6 PASS). With remember_filters off in Tauri the query is kept the same way. The probe's first back click hit the sidebar Total Stats link, not the kicker link; the kicker link is `a.inline-flex`.
- A stored `global.params` with the page opened directly: Electron restores it. Tauri did not (bug, fixed in c42a566). The router drops a navigation made while it lands the first location, so the restore in `onSettled` never ran, and the write effect overwrote the stored query with an empty one. The restore now runs a tick later and the write effect starts after it. After the fix Tauri lands on `#/global?tab=augments&patch=16.22`. An explicit query wins over the stored one, as in Electron.
- The `g-restore`, `g-deeplink` and `g-open-back` pixels differ from Electron only in data: the replay serves the unfiltered golden for any patch or queue.
