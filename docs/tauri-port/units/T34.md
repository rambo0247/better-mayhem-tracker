# T34 Live Game page

Branch `port/T34-live-game`, from `port/T27-ui-shell` at 590cfaf.

## Built

- `tauri/src/pages/LiveGame.tsx`: the decision tree (loading, live, loading screen, waiting with earlier recap, standby offline, standby with client status, no games ever, last game recap).
- `tauri/src/pages/liveGameState.ts`: the tree's decisions as pure functions, so the unit test can run without a DOM or `window.api`.
- `tauri/src/components/GameRecap.tsx`: all of the recap, also used by T37.
- `tauri/src/pages/LiveGame.test.tsx`: snapshot sequences and recap screens (22 tests pass).

The clock is one signal written by a `setInterval` in `onSettled`, cleared in its cleanup.

## Dependencies not on the base

`MatchScoreboard` and `LiveScoreboard` (T27 tier 3) and `ExportImage` (T29). Typecheck and lint were run with uncommitted stubs of them. `ExportImage` is assumed to keep the React shape, with `message` an accessor: `useImageExport()` returns `{ busyWith, message(), run }`, `ExportImageMessage` takes `message` as a value, and `ExportImageButton` takes `action`, `card`, `exporting`.

## Not done
