# T35 Port the Trends page

Branch `port/T35-trends`, based on `port/T27-ui-shell` at 590cfaf.

## Built

- `tauri/src/pages/Trends.tsx`: the page, the queue select, the month and week toggle with the 120-day default, the activity heatmap, patch bars, the time series charts, the weekday and hour charts, and hover tooltips.
- `tauri/src/lib/trends.ts`: bucketing, the default granularity, the chart geometry, the win rate axis. Pure functions so bun can test them without the Solid JSX transform.

## Unit evidence

- `tauri/src/lib/trends.test.ts` asserts the default granularity for 100 and 200 day spans, bucket gaps, and the polyline and area path strings for one chart against the strings the React code's math produces on the same data.
- `bun run typecheck`, `lint`, `fmt:check`, `test`, `build` pass.

## Deviations

- The plan names `tauri/src/pages/Trends.test.tsx`. App.tsx loads every `pages/*.tsx` through `import.meta.glob`, so a test file there would be bundled into the app and import `bun:test`. The test lives at `src/lib/trends.test.ts`. The root should decide whether to exclude `*.test.tsx` in the glob.
- Bun cannot import a `.tsx` page (no Solid JSX transform), hence the `lib/trends.ts` split.
