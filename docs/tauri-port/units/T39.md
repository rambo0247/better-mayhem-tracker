## Done

- `.github/workflows/tauri-release.yml`: `tauri-v*` tags and `workflow_dispatch`, bun canary, `bun install --frozen-lockfile`, lint, fmt:check, typecheck, test, then `tauri build` on macos-latest (arm64 and x64, `--bundles app`) and windows-latest (x64, `--no-bundle`). The version comes from the tag, or the dispatch input. A tag run ends in a `publish` job that creates a prerelease named after the tag, which the 1.2.1 updater skips. A dispatch run uploads workflow artifacts and creates no release. `release.yml` and `v*` tags are untouched.

- E8: `src-tauri/src/webview2.rs` checks the EdgeUpdate registry key for the runtime, and without it shows a message box with Microsoft's link and exits. `main.rs` calls it first.
- Workflow steps: Info.plist id, executable and version, codesign verify, no `bmt-parity-driver` or `BMT_PARITY_TOKEN` in the release binary, lockfiles unchanged, launch of the unzipped arm64 app (alive after 15 s), the mac swap smoke test run against the Tauri bundle, and the Windows exe launched from a temp folder.
